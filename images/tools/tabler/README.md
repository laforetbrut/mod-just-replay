# Tabler Icons (subset)

A subset of [Tabler Icons](https://tabler.io/icons) 3.31.0 (outline and filled), MIT license (see
`LICENSE`), used by `scripts/vector.py` to draw the pictograms of badges, titles and feature icons.
Add an icon by copying its SVG from the same version into `outline/` or `filled/` and mapping a name
to it in `vector.ICONS` or `vector.BRANDS`. Brand icons show trademarks of their owners and are used
only to point to their services.
