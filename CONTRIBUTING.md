# Contributing

Just Replay (mod id `justreplay`), author / auteur : vyrriox.

- [English](#contributing)
- [Français](#contribuer)

Questions, bugs and feature requests: [GitHub issues](https://github.com/laforetbrut/mod-just-replay/issues).

## Rules

- `main` holds everything. Open every pull request against `main`, from `feat/<name>` or `fix/<name>`.
- Target branches (`neoforge-1.21.1`...) are generated by `tools/make_branches.sh`. Never edit them by hand.
- There is no root build. Build and run from a target folder:

  ```
  cd neoforge-1.21.1
  ./gradlew build --no-build-cache
  ./gradlew runClient -Pselftest
  ```

- Code shared by the loaders of a Minecraft version goes in `common/<mcversion>/` and must not import a loader package. A change in common is compiled on every loader of that version.
- An integration stays off in `CompatTargets.java` until it was read against the mod's build for that loader. State what was run and what was only read in `docs/COMPATIBILITY.md`.
- Verify every mixin target against the real jar of the target before launching: a compile does not check them.
- Commit messages are in English: `type: descriptive message`. Documents are bilingual, English then French.
- By contributing you agree that your work is licensed under Apache-2.0.

Toolchains, the production self test and the branch model are in [docs/BUILDING.md](docs/BUILDING.md).

# Contribuer

Questions, bugs et demandes : [tickets GitHub](https://github.com/laforetbrut/mod-just-replay/issues).

## Règles

- `main` contient tout. Toute pull request vise `main`, depuis `feat/<nom>` ou `fix/<nom>`.
- Les branches de cible (`neoforge-1.21.1`...) sont générées par `tools/make_branches.sh`. Ne jamais les modifier à la main.
- Il n'y a pas de build à la racine. Compiler et lancer depuis le dossier d'une cible :

  ```
  cd neoforge-1.21.1
  ./gradlew build --no-build-cache
  ./gradlew runClient -Pselftest
  ```

- Le code partagé par les loaders d'une version de Minecraft va dans `common/<mcversion>/` et n'importe aucun package de loader. Un changement dans common se compile sur chaque loader de cette version.
- Une intégration reste coupée dans `CompatTargets.java` tant qu'elle n'a pas été lue d'après le build du mod pour ce loader. Indiquer dans `docs/COMPATIBILITY.md` ce qui a été exécuté et ce qui a seulement été lu.
- Vérifier chaque cible de mixin sur le vrai jar de la cible avant de lancer le jeu : la compilation ne les contrôle pas.
- Messages de commit en anglais : `type: message descriptif`. Les documents sont bilingues, anglais puis français.
- En contribuant, vous acceptez que votre travail soit sous licence Apache-2.0.

Les outils, le test en production et le modèle de branches sont dans [docs/BUILDING.md](docs/BUILDING.md).
